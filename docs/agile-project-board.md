# Student Assignment Tracker
## Agile Project Management – COMP229 Project Part 2

### Project Overview
Student Assignment Tracker is a MERN Stack web application developed for COMP229 – Web Application Development at Centennial College.

The application helps students organize assignments, manage deadlines, and track their academic progress.

### Agile Project Management Tool
Our team uses Trello to organize and monitor project tasks.

**Trello Board:** [View Our Trello Board] (https://trello.com/b/47dfURLw/student-assignment-tracker-project-part-2)

The board contains four lists:

1. **Product Backlog:** Planned features and remaining project requirements.
2. **To Do:** Tasks ready to be started.
3. **Doing:** Tasks currently being worked on.
4. **Done:** Completed tasks and implemented user stories.

### Completed User Stories
- US-01: Create a New Assignment
- US-02: View My Assignments
- US-03: Edit an Assignment
- US-04: Mark an Assignment as Completed
- US-05: Delete an Assignment
- US-06: Create a Student Account
- US-07: Sign In to Student Assignment Tracker

### Remaining Project Tasks
- Deploy the application to the cloud.
- Complete unit and Cypress end-to-end testing.
- Demonstrate CI/CD using GitHub.
- Complete the External Design Document (EDD v3).
- Improve application performance.
- Finalize the UI and responsive design.
- Verify user and assignment CRUD operations.
- Prepare the project demonstration and slides.
- Prepare the final project submission.
- Test Sign Out and invalid login attempts.

### Team Collaboration
All six team members collaborate on development and project management.

Team members use the Trello board to review tasks, coordinate responsibilities, and update progress.

Code contributions are managed through GitHub branches, commits, and Pull Requests.

### Testing
On November 24, 2026, the following features were successfully tested locally:

- Student account registration
- Student sign-in
- Creating assignments
- Viewing assignments
- Editing assignments
- Marking assignments as completed
- Deleting assignments

These were manual tests. Additional automated testing and verification are still required.
